
# WeatherVerse 🌦️

WeatherVerse is a weather analytics application built with Python and Streamlit.

## Features
- Animated weather-themed interface
- Weather data visualization
- Interactive charts and analytics
- CSV upload and data analysis
- Temperature trend estimation

## Technologies
- Python
- Streamlit
- Pandas
- NumPy
- Plotly

## Run locally
Install dependencies:

    pip install -r requirements.txt

Start the app:

    streamlit run app_weatherverse_live.py
